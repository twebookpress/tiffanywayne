# Tiffany Wayne — optimized GitHub Pages website

Both cover images are included as WebP files, resized to a maximum width of 900 pixels with their original proportions preserved. The site uses relative links and needs no build step.

## Publish

1. Unzip this package.
2. Create a public GitHub repository named `tiffanywayne` under `twebookpress`.
3. Upload the contents of the extracted folder, including the entire assets folder. Keep index.html at the repository root.
4. Commit to main.
5. Under Settings → Pages, choose Deploy from a branch, main, /(root), then Save.

Your expected address is https://twebookpress.github.io/tiffanywayne/ once GitHub finishes publishing.

The preorder link points to https://www.amazon.com/dp/B0HLY9PJB9.
All newsletter buttons point to https://tiffany-wayne.kit.com/d0032a8fa7.
